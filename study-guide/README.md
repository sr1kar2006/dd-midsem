# DD F215 — Midsem Open-Book Study Guide

| File | What's inside |
|---|---|
| [`01_Combinational_Notes.md`](01_Combinational_Notes.md) | **Section 1:** all theory before sequential circuits, from scratch: number systems → Boolean algebra → K-maps/QM → NAND/NOR → adders, subtractors, CLA, BCD adder → decoders, encoders, muxes, demuxes → PLDs → Verilog. Includes worked past-paper problems (Quiz 2, Midsem 2024 & 2025, Compre) and **⚠️ EXAM TRICK** call-outs. |
| [`02_Tutorial_Solutions.md`](02_Tutorial_Solutions.md) | **Section 2:** step-by-step solutions to Tut-3 → Tut-7 (including latches, flip-flops, counters, FSMs; register questions excluded), with K-maps, state tables, ASCII circuits and a "Key Logic & Takeaway" per question. Bonus: two past midsem FSM/counter problems. |

**How to use it in the exam:** search the file for the block or the keyword (e.g. `EXAM TRICK`, `mux`, `PLA`, `overflow`, `excitation`). Every section starts with the method and ends with the traps.

All K-map minimisations were cross-checked with an exhaustive Quine–McCluskey run, and the designed circuits were simulated over every input combination.
